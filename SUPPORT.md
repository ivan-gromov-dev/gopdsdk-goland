# Support

Report defects and request features at
<https://github.com/ivan-gromov-dev/gopdsdk-goland/issues>.

Include the operating system, exact GoLand build, plugin version, `gopdsdk`
version, reproduction steps, and sanitized Language Services logs. Do not post
private source code, credentials, signing material, device logs, or personal
paths. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).
