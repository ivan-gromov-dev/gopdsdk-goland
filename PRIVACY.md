# Privacy

The plugin starts the locally installed `gopdsdk lsp` process and exchanges
language-server messages for files in the opened project. It does not add
telemetry, analytics, advertising, or publisher-operated network services, and
does not send source code to the plugin publisher.

GoLand, JetBrains Marketplace, the operating system, and software installed by
the user have their own privacy practices. When reporting a problem, review and
redact logs and project paths before sharing them.
